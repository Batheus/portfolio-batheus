Automação e Otimização de Redes com Análise Inteligente via Google Gemini

O script permite a aplicação automática das correções, gerenciando credenciais de forma segura através de variáveis de ambiente.

Pipeline ETL Serverless na AWS: Ingestão e Análise de Dados da B3 com AWS Glue

Pipeline de engenharia de dados "serverless" e orientado a eventos na AWS. O projeto automatiza a ingestão de dados financeiros da B3 utilizando Python (yfinance) e boto3. A arquitetura aciona automaticamente (via AWS Lambda) jobs ETL no AWS Glue (PySpark) ao detectar novos arquivos no S3. Os dados processados são catalogados pelo Glue Crawler e disponibilizados para análise SQL performática no Amazon Athena, seguindo as melhores práticas de Data Lakehouse.
